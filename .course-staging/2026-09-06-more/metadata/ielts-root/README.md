# IELTS Test Tracking

Created: 2026-06-26
Status: Active tracking folder

This folder tracks IELTS-test-related materials and skills.

Original course files stay in their source folders. Review copies now live in
the real skill folders under each `materials` subfolder.

## Folder Map

- `00. dashboard`: overall IELTS readiness and material index
- `01. reading`: IELTS Reading skills, practice queue, and result review
- `02. listening`: IELTS Listening skills and future practice tracker
- `03. writing`: IELTS Writing Task 1 / Task 2 tracker
- `04. speaking`: IELTS Speaking skills and future practice tracker
- `05. vocabulary-grammar`: vocabulary, grammar, proofreading, and sentence-control support
- `06. scores`: score log and mistake review

## Rule

Do not mark a skill or practice set complete unless there is evidence:

- score result
- submitted form
- completed PDF answers
- explicit user confirmation
